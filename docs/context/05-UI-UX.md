# 05 — UI / UX

## Principles

- Mobile first; phone-based study primary
- Extremely easy to understand; few taps
- Fast; accessible; responsive
- Professional marine/radio association without gimmicks
- Prefer a simple page over a large dashboard

## Primary practice loop

```
QUESTION → ANSWER → RESULT → EXPLANATION → NEXT
```

Do not reveal the correct answer before submission.

## Accessibility

- Semantic HTML
- Keyboard access + clear focus
- Adequate contrast
- Associated labels
- Large touch targets
- Screen-reader compatible answer controls
- Announce result/status changes
- Do not rely on colour alone for correct/incorrect

## Visual direction (implementation stages)

- Marine radio atmosphere (sea/sky/radio context) without clutter
- Brand-forward public pages
- Avoid generic AI aesthetic defaults (see project frontend rules)
- One job per section; no card-heavy heroes

## Admin UX

- Searchable tables with pagination
- Clear flag/review workflows
- Import batch inspection
- No casual inline overwrite of canonical educational text
